# Redimensionador de Vídeos

Redimensiona vídeos em massa para as proporções de anúncios da Meta (9:16, 4:5, 1:1, 16:9) sem distorcer: detecta a proporção, sugere o melhor formato e converte direto no navegador (WebCodecs, aceleração de hardware). Saída MP4 H.264 + AAC em 1080p.

Site estático: publique esta pasta como está na Netlify ou na Vercel (sem build). Use Chrome ou Edge.
